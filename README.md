# Asistente Ley 29090 — Motor de decisión (MVP)

Web estática (GitHub Pages) que:
- Determina modalidad (A–D o EXENTA) para **Edificación**
- Sugiere ruta (Municipalidad / Comisión Técnica / Revisores Urbanos)
- Genera checklist y alertas básicas

## Ejecutar local
Abrir `docs/index.html` en Chrome/Edge.

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → Branch: main → Folder: /docs

## Nota
Este MVP modela reglas para apoyo; no sustituye verificación normativa final del caso.
